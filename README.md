# TeamS Offshore — Homepage Redesign

A modern, responsive homepage redesign for TeamS Offshore, focused on creating a stronger first impression and encouraging visitors to explore the company's offshore staffing and technology services.

## Overview

The redesign introduces a cleaner visual identity, stronger content hierarchy, and clearer calls to action while keeping the experience professional and approachable for a B2B audience.

## Highlights

- Responsive desktop, tablet, and mobile layout
- Modern hero section with clear primary CTA
- Service-focused homepage structure
- Interactive service cards
- Global talent / region section
- Scroll reveal animations
- Smooth internal navigation
- Responsive mobile navigation
- Keyboard-accessible interactive elements
- WCAG-conscious contrast and focus states
- Lightweight HTML, CSS, and JavaScript implementation

## Sections

- Hero
- Services
- Why TeamS
- Global Talent
- Conversion CTA
- Footer

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Local image assets

Design Direction

The visual direction combines premium B2B aesthetics with a human-centered approach. The design uses strong typography, generous spacing, restrained motion, high-quality imagery, and a focused accent color to create a professional but engaging experience.

Accessibility

The interface includes semantic HTML, visible keyboard focus states, keyboard interaction for interactive region cards, appropriate image alt text, and support for reduced-motion preferences.
